# 第二阶段：连续底形、独立线条与语义图层

## 按对象理解原图

逐区记录完整器官/组织底形、内部结构、细胞及细胞核、路线、箭头、引线、虚线、图例符号和必要阴影。去字版本可生成追踪候选，仍以原图判断真实结构，防止遮罩误伤成为新轮廓。

区分真实对象边界、真实遮挡边界，以及仅由明暗和抗锯齿产生的边界。后者通常不应生成独立轮廓。

## 构造顺序

常见顺序为完整底形、连续组织层/管腔/血管、必要阴影与内部分界、路线、细胞细节、注释引线，最后放冻结文字。实际前后关系由源图决定：神经末端在细胞前时，细胞必须先画；边框也可能位于穿越它的线路下面。

从可测轮廓拟合闭合曲线，保持凸凹转折、叶裂和比例。自动分割的“可见颜色区域”在被前景遮挡处会缺口，需要补全底形在前景之下的延伸。

- 一个连续组织层通常用一个完整闭合对象；相邻但独立的组织保持独立。
- 阴影可用渐变或少量受底形约束的覆盖面，不以数百细色块拼器官。
- 在检查副本中隐藏前景：底形仍应完整，不留下神经形状的洞。
- 补底形不是填所有孔洞。真实管腔、器官间背景和分离部位应保留。

## 线条与追踪

简单曲线优先用原生中心线与明确线宽；变宽带状对象可用完整填充轮廓。一条真实线通常只需一条路线，必要的暗边+内色可保留两个有明确作用的对象。不能把每个明暗级别当作一条线叠加。

- 在无遮挡直线段测量可见宽度，并沿曲线多处检查。不要将模糊边缘全部当作实线。
- 普通 filled contour 不再额外加 stroke；需要边框时将它计入总可见宽度。
- 中心线与箭头只绘制一次，方向与原图一致，注意末端、接头和圆角。
- 同色线路的交叉不自动代表相连。保留桥接、空隙、遮挡和真正的分叉。
- 同色但不同器官/细胞/线路不要为减少对象数并成难以编辑的巨型对象。

自动追踪可在语义 ROI 内提供候选。先合并同一对象的相近色，再追踪轮廓；色板和阈值从当前图确定。颜色/饱和度只是线索：暗红血管边缘可能被误当神经，灰蓝软骨可能被误当蓝色线路。

若用 VTracer，优先比较不透明 RGB 与语义二值掩膜的结果；透明输入、多色堆叠和抗锯齿可能产生伪色层。这是诊断经验，不是固定参数表。看实际输出后决定是否采用。

二值掩膜须保留合法孔洞。平滑/补洞只处理已确认的像素台阶或采样空隙，不能连接本来独立的线路。不要按全图面积阈值删除小路径：箭头、颗粒、虚线和释放符号可能本来就很小。

## 修复过度分层版本

1. 统计各语义区域的对象数、近似颜色和层序，定位问题。
2. 对照源图确定真实对象被拆成哪些路径，建立替代底形/路线。
3. 在副本中用替代对象替换旧碎片，而非在旧碎片上加新线。
4. 补回简化中丢失的真实结构：细胞分隔、核、通道、末端、细虚线和箭头等。
5. 检查隐藏前景后的底形、移动对象后的残留和交叉处线宽，再审查全页。

对象数下降也可能说明内容被删除。区域清单和实际编辑试验比总数更有意义；结构审计“通过”不能替代这些检查。

## 原生实现约定

Freeform 使用稳定名称和语义分组。不能嵌入整张位图或仅置入整幅 SVG 后声称每个对象都可原生编辑。复杂纹理需要保留栅格时须符合用户范围并记录对象。

合并 PPTX XML 时动态分配未使用 ID，正确迁移关系/媒体/命名空间。仅删除已被替换且无其他引用的旧背景关系与媒体。保留文字和祖先有效变换，避免硬编码 shape ID、图片名或组名。

SVG 路径转 PowerPoint 时正确处理局部 bbox、平移、相对命令、close、控制点和孔洞方向。不要简单拆分 d 字符串猜坐标。重新量化坐标前先证明误差不会改变细线和微小符号。
